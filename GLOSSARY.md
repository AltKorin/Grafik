# Słownik — Grafik

Język UI i rozmów z klientem. Kod po angielsku (w nawiasie), UI zawsze po polsku.

| Termin | Znaczenie |
| --- | --- |
| **Firma** (`Workplace`) | Klient: restauracja, hotel, sklep. Jedno konto Grafiku = jedna firma (osoba może należeć do kilku). |
| **Dział** (`Department`) | Zespół w firmie: kuchnia, sala, recepcja. Ma kolor w grafiku. |
| **Pracownik** (`Employee`) | Osoba w grafiku. Login opcjonalny (osoba tylko z kartą go nie ma). |
| **Dyrektor / kierownik działu / pracownik** | Role — zob. PLAN.md §2. |
| **Zmiana** (`Shift`) | Godziny pracy osoby w dniu, od–do; może kończyć się następnego dnia. |
| **Grafik** | Siatka osoby × dni tygodnia. |
| **Niedyspozycyjność** (`Unavailability`) | Urlop, L4 albo niedostępność — zgłaszana bez akceptacji, blokuje zmiany. |
| **Wniosek** (`ChangeRequest`) | Prośba o zamianę, odwołanie, inne godziny lub dodatkową zmianę; przyjmuje kierownik. |
| **Punkt odbić** (`ClockPoint`) | Wejście do pracy: naklejka NFC i/lub kiosk. |
| **Naklejka NFC** | Tag z linkiem punktu; pracownik przykłada swój zalogowany telefon. |
| **Kiosk** | Tablet przy wejściu: karta/brelok przy czytniku. Link z sekretem, pokazywany raz. |
| **Odbicie** (`Punch`) | Zdarzenie wejście / wyjście. Niezmienialne. |
| **Korekta** | Odbicie dopisane przez kierownika (z powodem) albo anulowanie pomyłki (z powodem). |
| **Do wyjaśnienia** | Brak wyjścia lub wyjście bez wejścia w zestawieniu. |
| **Czas pracy** | Zestawienie miesiąca: plan z grafiku vs przepracowane z odbić. |
